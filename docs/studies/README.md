## Purpose

This directory explains each experiment as a scientific unit. It connects the
question and conditions to the Python implementation, immutable tracked
inputs, generated output, and external repositories.

## Available studies

- [Haiu comparison](haiu_comparison.md): DMW with a complete ontology, DMW
  with Haiu retrieval, and standalone Haiu retrieval on 480 header--sublemma
  units.

## Synchronization rule

Every study has an operational README below the top-level `studies/`
directory. Repetition is intentional. Update a study chapter and its
operational README together whenever scientific behavior, paths, dependency
releases, or evidence rules change.
