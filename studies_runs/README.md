# Study runs

Actual full runs copied from `studies_run_templates/` belong below their study
directory. They remain wholly ignored until the user deliberately prepares and
copies one into `haiu_comparison/git_tracked/<run-id>/`.

Do not create runs below the old `studies/` or `output/` paths.

Use `AGENT_CHAT.md` for low-frequency coordination with an agent babysitting a
long run. Run evidence and routine checkpoints still belong in that run's
ignored `logs/BABYSIT-*.md` journal.
